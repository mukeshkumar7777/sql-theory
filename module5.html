13.String, Date, Math & NULL Safeguards
Scalar Operations
Student Intuition: Essential utility functions for parsing raw values, computing durations, and preventing runtime errors (such as dividing by zero).
Example String Manipulation & Substring Parsing
SELECT 
    CONCAT_WS(', ', last_name, first_name) AS formatted_name,
    SUBSTRING(email FROM 1 FOR POSITION('@' IN email) - 1) AS username,
    TRIM(BOTH ' ' FROM phone_number) AS clean_phone
FROM users;
Example Date Math & Divide-by-Zero Guard
SELECT 
    order_id,
    -- Date arithmetic: Age in days
    CURRENT_DATE - order_date AS days_elapsed,
    -- NULLIF converts 0 to NULL, avoiding divide-by-zero errors
    revenue / NULLIF(units_sold, 0) AS unit_price
FROM sales_orders;
14.CASE Expressions & Pivoting Rows into Columns
Cross-Tabulation
Student Intuition: Conditional aggregation pairs SUM(CASE WHEN ...) with GROUP BY to pivot categorical rows into separate columns.
Example Quarterly Revenue Pivot Table
SELECT 
    product_name,
    SUM(CASE WHEN quarter = 'Q1' THEN sales ELSE 0 END) AS q1_sales,
    SUM(CASE WHEN quarter = 'Q2' THEN sales ELSE 0 END) AS q2_sales,
    SUM(CASE WHEN quarter = 'Q3' THEN sales ELSE 0 END) AS q3_sales,
    SUM(CASE WHEN quarter = 'Q4' THEN sales ELSE 0 END) AS q4_sales
FROM quarterly_sales
GROUP BY product_name;
