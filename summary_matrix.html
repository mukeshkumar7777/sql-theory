# Topic Key Syntax / Clause What to Say in the Interview
01 TRUNCATE vs DELETE TRUNCATE vs DELETE TRUNCATE is DDL (deallocates pages, resets IDs); DELETE is DML (row-by-row, logged).
02 NULL Logic (3VL) IS NULL, IS NOT NULL SQL uses Three-Valued Logic. = NULL yields UNKNOWN and returns zero rows.
03 Execution Order FROM → WHERE → GROUP BY → SELECT Column aliases created in SELECT cannot be used in WHERE because WHERE runs earlier.
04 INNER vs OUTER Joins INNER, LEFT, FULL JOIN INNER drops non-matches; LEFT keeps all left rows; FULL keeps all rows from both.
05 Anti-Join Pattern LEFT JOIN ... WHERE right.id IS NULL Optimal way to identify missing relationships without expensive subqueries.
06 NOT IN NULL Pitfall NOT EXISTS NOT IN returns zero rows if the subquery contains a single NULL. Use NOT EXISTS.
07 Rank Functions ROW_NUMBER, RANK, DENSE_RANK ROW_NUMBER is strictly sequential; RANK skips numbers on ties; DENSE_RANK has no gaps.
08 N-th Salary DENSE_RANK() OVER (ORDER BY salary DESC) DENSE_RANK handles duplicate salary ties cleanly across departments.
09 Gaps & Islands date - ROW_NUMBER() * INTERVAL Subtracting a sequential row number produces a constant anchor date for consecutive days.
10 SARGable Indexes WHERE date >= '2024-01-01' Never wrap indexed columns in functions; keep columns bare to enable B-Tree seeks.
