Module 6: Top 3 Placement Problem Patterns Interview Coding Round
Pattern 1.Find N-th Highest Salary (3 Implementations)
Asked in 90% of Interviews
Student Intuition: Always handle duplicate salaries using DENSE_RANK() or DISTINCT so ties receive the same rank.
Method A: DENSE_RANK() (Recommended Standard)
WITH RankedSalaries AS (
    SELECT salary, DENSE_RANK() OVER (ORDER BY salary DESC) AS rnk
    FROM employees
)
SELECT DISTINCT salary FROM RankedSalaries WHERE rnk = 2;  -- Change '2' to N
Method B: Correlated Subquery (Universal ANSI SQL)
SELECT DISTINCT salary
FROM employees e1
WHERE 2 = (  -- Change '2' to N
    SELECT COUNT(DISTINCT salary)
    FROM employees e2
    WHERE e2.salary >= e1.salary
);
Method C: LIMIT / OFFSET
SELECT DISTINCT salary 
FROM employees 
ORDER BY salary DESC 
LIMIT 1 OFFSET 1;  -- OFFSET is (N - 1), so OFFSET 1 = 2nd highest
Pattern 2.Department-wise Top 3 Earners
LeetCode Benchmark
Student Intuition: Partition by department and order by salary descending within a CTE, then filter the calculated rank.
Solution Complete Query
WITH DeptRanks AS (
    SELECT 
        d.dept_name, e.name AS employee_name, e.salary,
        DENSE_RANK() OVER (
            PARTITION BY e.department_id 
            ORDER BY e.salary DESC
        ) AS rank_in_dept
    FROM employees e
    JOIN departments d ON e.department_id = d.id
)
SELECT dept_name, employee_name, salary
FROM DeptRanks
WHERE rank_in_dept <= 3;
Pattern 3.Consecutive Login Streaks (Gaps & Islands)
Advanced Placement Problem
Student Intuition: Subtracting a row number from consecutive calendar dates produces a constant group anchor date for the entire active streak.
Solution Find Users with 3+ Consecutive Active Days
WITH DedupedLogins AS (
    SELECT DISTINCT user_id, login_date FROM user_logins
  ),
  StreakGroups AS (
    SELECT 
        user_id, login_date,
        login_date - (ROW_NUMBER() OVER (PARTITION BY user_id ORDER BY login_date) * INTERVAL '1 day') AS streak_anchor
    FROM DedupedLogins
  )
SELECT 
    user_id, 
    MIN(login_date) AS streak_start, 
    MAX(login_date) AS streak_end, 
    COUNT(*) AS streak_length
FROM StreakGroups
GROUP BY user_id, streak_anchor
HAVING COUNT(*) >= 3;
