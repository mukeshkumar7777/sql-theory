04.1. INNER JOIN (Equi-Join & Non-Equi Join)
Exact Intersection
Student Intuition: Returns rows only when the join condition evaluates to true in both tables. Discards all non-matching records.
Equi-Join Example Matching Primary and Foreign Keys
SELECT e.name AS emp_name, d.dept_name
FROM employees e
INNER JOIN departments d ON e.department_id = d.id;
Non-Equi Join Example Joining on Value Ranges (>=, <=) 
-- Match employees to salary grades where salary falls between min and max bounds
SELECT e.name, e.salary, g.grade_level
FROM employees e
INNER JOIN salary_grades g 
    ON e.salary BETWEEN g.min_salary AND g.max_salary;
05.2. LEFT JOIN & 3. RIGHT JOIN
Outer Directional Joins
Student Intuition:
  • LEFT JOIN: Keeps all rows from the left table. If no match exists on the right, right columns fill with NULL.
  • RIGHT JOIN: Keeps all rows from the right table, filling unmatched left columns with NULL. (In industry, LEFT JOIN is preferred for readability).
LEFT JOIN Example All Customers Regardless of Order History
SELECT c.name, o.order_id, o.total_amount
FROM customers c
LEFT JOIN orders o ON c.id = o.customer_id;
RIGHT JOIN Example All Departments Regardless of Assigned Employees
SELECT e.name, d.dept_name
FROM employees e
RIGHT JOIN departments d ON e.department_id = d.id;
06.4. FULL OUTER JOIN
Complete Union of Datasets
Student Intuition: Combines LEFT JOIN and RIGHT JOIN. Preserves all rows from both tables, filling with NULL wherever a relationship does not exist.
Example Finding Unlinked Records Across Both Entities
-- Retains employees without departments AND departments with zero employees
SELECT e.name AS emp_name, d.dept_name
FROM employees e
FULL OUTER JOIN departments d ON e.department_id = d.id;
07.5. CROSS JOIN & 6. SELF JOIN
Cartesian Products & Hierarchies
Student Intuition:
  • CROSS JOIN: Cartesian product ($N \times M$ rows). Multiplies every row of table A by every row of table B.
  • SELF JOIN: Joining a table to itself using two distinct aliases to evaluate intra-table hierarchies.
CROSS JOIN Example Generating Permutations (All Sizes x All Colors)
SELECT s.size_label, c.color_name
FROM sizes s
CROSS JOIN colors c;
SELF JOIN Example Finding Employees Earning More Than Their Managers
SELECT 
    e.name AS employee_name, e.salary AS emp_salary,
    m.name AS manager_name, m.salary AS manager_salary
FROM employees e
JOIN employees m ON e.manager_id = m.emp_id
WHERE e.salary > m.salary;
08.7. Anti-Join, 8. Semi-Join & 9. NATURAL JOIN
Special Join Architectures
Student Intuition:
  • Anti-Join: Identifies records in table A that have no matching rows in table B (LEFT JOIN ... WHERE B.id IS NULL).
  • Semi-Join: Returns rows from table A if they exist in table B, without duplicating rows if table B has multiple matches (EXISTS).
  • NATURAL JOIN: Automatically matches all columns with identical names across tables. (Interviewers warn against this because schema changes break queries silently).
Anti-Join Example Customers with Zero Orders
SELECT c.id, c.name
FROM customers c
LEFT JOIN orders o ON c.id = o.customer_id
WHERE o.id IS NULL;  -- Anti-join filter
Semi-Join Example Customers Who Placed at Least One Order
SELECT c.id, c.name
FROM customers c
WHERE EXISTS (
    SELECT 1 FROM orders o WHERE o.customer_id = c.id
);
NATURAL JOIN Example Implicit Column Matching
-- Joins implicitly on identical column names (e.g. department_id)
SELECT * FROM employees NATURAL JOIN departments;
